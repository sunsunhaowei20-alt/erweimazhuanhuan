# 二维码生成器

输入文字或网址，在网页里直接生成二维码。全部在浏览器完成，不经过后端、不上传内容。

GitHub 仓库：[sunsunhaowei20-alt/erweimazhuanhuan](https://github.com/sunsunhaowei20-alt/erweimazhuanhuan)

## 功能

- 输入任意文字或 `http(s)` 网址，即时生成二维码
- 调整尺寸、容错等级、前景色和背景色
- 下载 PNG，或复制图片到剪贴板

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://localhost:3000`）。

## 构建

```bash
npm run build
npm start
```
